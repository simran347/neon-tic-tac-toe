# 🎮 Neon Tic-Tac-Toe

A modern Tic-Tac-Toe game built with **HTML, CSS, and JavaScript**, featuring a neon-inspired interface, smooth animations, interactive gameplay, and score tracking.

## ✨ Features

- 🌌 Modern neon-themed design
- ❎ Interactive X and O gameplay
- 🏆 Scoreboard for Player X, Player O, and draws
- 💡 Highlighted winning combinations
- 🤝 Draw detection
- 🔄 Restart the round without clearing scores
- 🆕 Start a new match and reset the scoreboard
- 📱 Responsive layout for desktop and mobile

## 🛠️ Built With

- **HTML5** — page structure
- **CSS3** — styling, layout, and animations
- **JavaScript** — game logic and interactivity

## 🚀 Getting Started

### Run locally

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/neon-tic-tac-toe.git
   ```

2. Open the project folder in VS Code.
3. Open `Tic_tactoe.html` in your browser.

   Alternatively, use the **Live Server** extension in VS Code and choose **Open with Live Server**.

> Replace `YOUR-USERNAME` in the clone command with your GitHub username.

## 🎯 How to Play

1. Open the game in your browser.
2. Players take turns selecting an empty square.
3. The first player to align three marks horizontally, vertically, or diagonally wins.
4. If all squares are filled without a winning combination, the round is a draw.
5. Use **Restart Round** to play again while keeping the scores, or **New Match** to reset the scores.
